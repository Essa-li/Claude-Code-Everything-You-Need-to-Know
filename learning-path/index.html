结论

先学 8 课，约 2 小时 40 分钟，分两个晚上就能学完

第一晚学初级 4 课（会用、会控权限、会提交改动、会写项目记忆），第二晚学中级 4 课（把重复工作做成技能、整理记忆、管住权限、接外部工具）。学完就可以开始搭第一个“询盘分级”技能。

开始前准备

  1. 付费 Claude 套餐（Pro、Max、Team 或 Enterprise），或 Claude Console 账号。免费版不含 Claude Code。
  2. 电脑上装好 Node.js LTS 和 git，能打开终端。不熟终端先看官方 Terminal guide。
  3. 在 GitHub 打开 claude-code-practice，点 Use this template 建一个自己的练习仓库并克隆。所有练习都在那里做，不碰你的真实资料。
  4. 开两个终端窗口：一个运行 npm run learn（逐步带练、自动检查），另一个运行 claude。

学完后可以练手的业务场景

以下是练习方向，不是现成功能。先用脱敏的样例数据在练习仓库里做，确认结果可靠后再接真实资料。

项目记忆 CLAUDE.md · 初级第 5 课

写一份“公司与产品画像”

  1. 写清 AICRANE 与 AIMIX 的产品范围、达曼办公室的安装和备件能力。
  2. 写清客户评级标准 S/A/B/C 和输出格式。
  3. 新开会话验证 Claude 是否按画像回答。

注意：不写银行、合同金额、私人联系方式。

技能 Skill · 中级第 1 课

“询盘分级”技能

  1. 把每次分析询盘时重复的要求写成一个技能。
  2. 输出固定栏目：核心需求、紧迫度、决策链、产品匹配、风险、下一步、英文回复草稿。
  3. 输入一封询盘，输入技能名即可调用。

注意：草稿只是草稿，发出前人工确认。

权限与沙箱 · 中级第 4 课

给客户资料文件夹上锁

  1. 设置禁止读取 .env 等含账号密码的文件。
  2. 打开沙箱，限制命令只能写项目目录。
  3. 用 /permissions 确认规则已生效。

注意：先在练习仓库试，再用到真实文件夹。

MCP 外部工具 · 中级第 7 课

连接外部工具做背调

  1. 学会接入一个 MCP 服务器，并只给项目内使用。
  2. 之后可连接表格、邮箱等你已授权的工具，整理客户跟进台账。

注意：连接即授权读取，对外发送、发布仍需你明确确认。

8 个术语

Session 会话
一次和 Claude Code 的对话。会话越长，上下文越满，需要清理或压缩。
Context 上下文
Claude 当前“记得”的内容总量，包括对话、读过的文件和加载的说明。
Permission mode
权限模式：决定 Claude 改文件、跑命令前是否要你批准。
Plan mode
计划模式：Claude 先出方案，你批准后才动手改文件。
CLAUDE.md
项目记忆文件。每次新会话都会读，适合放公司画像、规则和输出格式。
Skill 技能
把一套重复的工作说明存成文件，输入名字就调用，请求匹配时也会自动加载。
Sandbox 沙箱
限制 Claude 运行的命令只能写入项目目录、临时目录和你加进来的目录。
MCP
连接外部工具和数据的标准协议，例如浏览器、数据库或某个服务的接口。
